# Emporio
Emporio è un prototipo di applicazione Java per gestire l’ipotetico inventario di un negozio o di un magazzino. Vi possono svolgere diverse azioni al fine di tenere traccia e gestire i prodotti disponibili. L'applicazione è frutto di un progetto scritto per un esame universitario di programmazione funzionale presso l'università di Camerino.
